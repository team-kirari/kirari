# 브라우저 이야기 임시저장

사용자 요청에 따라 작성 중인 글을 브라우저 `localStorage`에 저장합니다. 입력을 멈춘 뒤 약 400ms에 자동저장하며, 목록으로 돌아가기·페이지 종료·편집기 해제 시에도 마지막 내용을 저장하도록 구성했습니다. 다음 편집 시 같은 원본 revision의 자동저장을 복원합니다. 원본이 수정된 경우 이전 자동저장은 자동 적용하지 않고 사용자가 직접 불러올 수 있게 표시합니다.

최종 저장 버튼 옆의 **임시저장** 버튼을 누르면 슬롯 관리 팝업이 열립니다. 자동저장 상태·안내와 수동 슬롯은 이 팝업에 표시하고, 저장 실패 안내는 편집 화면에서도 표시합니다. 수동 슬롯 3개에는 버튼으로 현재 내용을 저장하고 불러오거나 삭제할 수 있습니다. 자동저장은 슬롯을 덮어쓰지 않습니다. 기존 슬롯 덮어쓰기와 작성 중인 내용 교체는 확인을 받습니다. 불러오면 팝업을 닫고 편집 화면에 적용합니다. 닫기 버튼과 Escape로 닫을 수 있으며 네이티브 dialog의 포커스 제어를 사용합니다. 새 글과 각 기존 글의 수정 화면, 로컬·원격 모드는 저장 공간을 구분합니다. 다른 기기·브라우저와 동기화하지 않습니다.

제목·작가명·본문·폰트·크기·작성 날짜·보호 설정과 저장 시각·원본 revision만 허용 목록으로 저장합니다. 제목·본문이 비어 있거나 날짜를 아직 선택하지 않은 상태도 보존합니다. 비밀번호·확인 값·인증정보는 저장하지 않으며, 불러올 때 비밀번호 입력을 비웁니다. 이 저장은 암호화 저장이나 접근 제어가 아닙니다. 원격 서버로 전송하는 동작은 기존 최종 저장 버튼에만 있습니다.

버전·제목/작가명 길이·폰트·크기·날짜·슬롯 수·revision·저장 시각과 원본 JSON 크기를 확인합니다. 본문 글자 수 제한은 없습니다. 편집 화면별 임시저장 JSON 전체는 2,500,000 UTF-16 코드 단위 이내로 읽기와 쓰기 모두 검사하며, 브라우저 자체 저장 용량 제한도 적용됩니다. 손상 데이터와 저장 공간 부족·브라우저 저장 차단은 화면에 실패를 표시합니다. 각 슬롯의 삭제와 현재 화면의 작성 내용·임시저장 전체 초기화를 제공합니다. 정상 최종 저장 시 자동저장은 지우고 수동 슬롯은 유지합니다. 최종 저장은 성공했지만 자동저장 정리가 실패하면 별도 안내를 표시합니다.

명령줄 타입 검사·린트·전체 테스트·빌드를 통과했습니다. 테스트는 미완성 본문과 일반 문자열 보존, 비밀번호 제외, 자동/수동 슬롯 분리·삭제, 화면별 키 분리, 손상·과대·위험 값 거부, 저장 차단·용량 초과 예외를 확인합니다. 실제 브라우저 화면·타이머·종료 이벤트와 운영 배포는 아직 확인하지 않았습니다.

화면에서는 합성 글로 다음을 확인합니다.

1. 내용을 입력하고 잠시 기다린 뒤 새로고침하거나 목록에서 다시 작성 화면으로 들어가면 내용·폰트·날짜가 복원됩니다.
2. 슬롯 1에 저장한 뒤 본문을 변경해도 슬롯 1의 내용은 유지되고, 불러오기로 복원할 수 있습니다. 나머지 슬롯도 독립적으로 동작합니다.
3. 비밀번호와 확인 값은 새로고침·슬롯 불러오기 후 비어 있습니다.
4. 최종 저장 후 자동저장은 지워지고 수동 슬롯은 남습니다. 슬롯 삭제·전체 초기화가 동작합니다.
5. 브라우저 저장을 차단하면 성공 메시지 대신 오류가 표시되고 현재 편집 내용은 유지됩니다.
