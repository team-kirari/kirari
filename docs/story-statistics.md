# 본문 통계

작성 화면의 100,000자 입력 제한과 최종 저장·브라우저 임시저장의 본문 글자 수 제한을 제거했습니다. 본문 아래에는 공백 포함·제외 글자 수, 단어 수, 단락 수, 문장 수를 표시합니다. 최종 저장의 요청 크기·아카이브 용량 제한과 브라우저 저장 공간 제한은 별도로 적용됩니다.

- 글자 수는 `Intl.Segmenter`의 grapheme 단위로 셉니다. 결합 문자와 가족 이모지도 화면상의 한 글자로 처리합니다. CRLF는 LF로 통일하고, 공백 포함 값에는 줄바꿈·탭도 포함합니다. 공백 제외 값에서는 Unicode 공백을 제외합니다.
- 단어와 문장은 한국어 `Intl.Segmenter`로 구분합니다. 단어는 `isWordLike`인 구간을 세고, 문장은 글자·숫자·이모지가 있는 구간을 셉니다. 마지막 미완성 문장도 하나로 셉니다. 약어·인용문 등의 집계는 브라우저의 언어 분할 규칙에 따릅니다.
- 단락은 렌더링과 같은 `storyBlocks` 규칙을 사용합니다. 빈 줄로 구분하고, 단독 `***` 장면 구분자는 단락·단어·문장에서 제외합니다. 글자 수에는 입력된 `***`도 포함합니다.
- 통계는 본문이 바뀔 때 갱신하고, React의 지연 값과 메모이제이션으로 다른 입력의 변경 때 불필요하게 다시 계산하지 않습니다.

명령줄 검사와 합성 데이터 테스트로 빈 글·공백·한글·영문·문장부호·줄바꿈·이모지·장면 구분 및 100,000자 초과 글의 로컬/원격/브라우저 저장을 확인했습니다. 실제 화면과 운영 배포는 확인하지 않았습니다. 화면에서는 글을 입력·붙여넣기한 뒤 다섯 통계가 갱신되고 100,000자를 넘어도 입력이 잘리지 않는지 확인합니다.
